# DATABASE_SCHEMA.md

## Purpose

The data contract of Salikha Studio OS: every worksheet, every column, data types, validation, keys, enums, audit fields, calculated fields, and example values. Deviation from this document is a contract violation.

## Scope

Applies to the Google Sheets workbook (the database) and every future data-layer module. Row 1 of each sheet is the header row; services read a header-to-column map and never hard-code column positions.

## Overview

The workbook is the single source of truth. Sheets are grouped into system-owned sheets and data sheets. All permanent IDs are immutable strings generated by `IdService` in the format `PREFIX-YYYY-XXXXXXXX` (e.g., `CLI-2026-8F3K2A9Q`). Spreadsheet row numbers are **never** used as IDs.

Conventions:

- Currency stored as numbers (never formatted strings); PHP is the business currency.
- Time stored as DateTime in business timezone (Asia/Manila).
- Booleans stored as `TRUE` / `FALSE`.
- Financial rows are never physically deleted (soft statuses and voiding only).
- System-controlled columns are written only by backend services, never by hand.
- Example values use the `CLI-2026-8F3K2A9Q` style and PHP amounts.

## 14. Calculated Fields Reference

| Field | Basis |
|---|---|
| Cash account balance | sum of POSTED signed transactions (the OPENING_BALANCE transaction is part of the ledger; `opening_balance` column is informational only) |
| Booking balanceRemaining | plan dues - sum of VERIFIED payments |
| Booking revenueTotal | sum(BookingItems.lineTotal) - discount + tax |
| Booking direct cost | material + transport + meals + crew + commission + other direct |
| Gross profit | revenueTotal - directCostTotal |
| Net profit | grossProfit - allocOpsCost |
| Profit margin % | netProfit / revenueTotal x 100 |
| Inventory on-hand | sum of remainingQty over active batches |
| Weighted average unit cost | sum(batch unitCost x qtyIn) / sum(qtyIn) |
| Inventory value | sum(remainingQty x unitCost) per batch |
| Deployment actual material cost | sum(consumedQty x unitCost) |
| Commission amount | baseAmount x ratePct / 100 |
| Expense netAmount | grossAmount - taxAmount |
| Daily reconciliation difference | actualClosing - expectedClosing |
| Equipment depreciation | purchasePrice / usefulLifeMonths (report-only) |

Statuses are POSTED/VOIDED. `BOOKING_PAYMENT` (INFLOW, INCOME category) classifies booking revenue; `REFUND` (OUTFLOW, REFUND category) classifies refunds separately from expenses. Recalculation triggers: transaction posted/voided, transfer posted/voided, opening balance recorded, payment recorded/voided, refund recorded/voided. All calculated values are recomputed by backend services; no sheet formulas are trusted as truth.
